For assigned requirement IDs, search official APIs/SDKs first, then suitable libraries, open source, and pretrained models. Compare only relevant options on capability, limitations, availability/cost, credentials, integration complexity, and fallback. Cover likely AI/API capability classes only when required, never by default.

Write concise, source-linked findings to `docs/research.md`; recommend an option only with evidence. Do not implement code or select architecture unilaterally.
